# How to work

This repository (Change-1byte.github.io) hosts my personal website at achange.life via GitHub Pages, with the custom domain configured under Settings → Pages. 

Each repository must enable GitHub Pages separately under Settings → Pages → Deploy from a branch → main → /(root) → Save.

The main repository (Change-1byte.github.io) uses the custom domain achange.life. Other repositories with GitHub Pages enabled **automatically** inherit this domain and use their repository names as URL paths (e.g., achange.life/summer-sublet-kate/).

Note: On GitHub Free, repositories must be public to use GitHub Pages. Making a repository private will unpublish its Pages site. If private, then change to public, need to unable github Page again.
